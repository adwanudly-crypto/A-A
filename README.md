# A-A Learning

A responsive React + Tailwind learning platform for exploring AI through projects, lessons, quizzes, and a demo learning buddy.

## Run locally

```sh
npm install
npm run dev
```

## Joke Generator

Open `/joke-generator` to get a random, kid-friendly joke. The feature requests a joke from [JokeAPI](https://v2.jokeapi.dev/) in safe mode, needs no API key, and includes loading and error handling.
